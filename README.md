# ⚓ Морской Бой (Battleship Web Game)

Интерактивная браузерная игра «Морской бой» с поддержкой искусственного интеллекта и звуковыми эффектами.

🚀 **[Играть онлайн](https://ваша-ссылка.netlify.app)** *(подставьте свою ссылку)*

---

## 🎮 Особенности игры
* 🤖 **Игра против Бота:** Умный ИИ с авто-поиском подбитых палуб.
* 👥 **Режим на двоих:** Игра с другом на одном устройстве с экраном передачи хода.
* 📱 **Адаптивный интерфейс:** Полная поддержка мобильных телефонов и планшетов.
* 🔊 **Звуковые эффекты:** Озвучка выстрелов, попаданий и победы через Web Audio API.
* 🔄 **Удобное управление:** Поворот кораблей кнопкой на экране или клавишей **R**.

---

## 🛠 Технологии
* **HTML5** — структура и сетка игровых полей
* **Tailwind CSS** — стилизация и адаптивный дизайн
* **JavaScript (ES6+)** — игровой движок, логика бота и звуковой контекст
