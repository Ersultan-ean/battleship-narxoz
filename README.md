# ⚓ Battleship Web Game (Морской Бой)

Интерактивная веб-игра «Морской Бой» с поддержкой искусственного интеллекта, адаптивным дизайном для мобильных устройств и звуковыми эффектами Web Audio API.

🌐 **Живая демо-версия:** [https://whimsical-meringue-0728b2.netlify.app](https://whimsical-meringue-0728b2.netlify.app)  
📁 **Репозиторий GitHub:** [https://github.com/Ersultan-ean/battleship-narxoz](https://github.com/Ersultan-ean/battleship-narxoz)

---

## 📌 Описание проекта
Данный проект представляет собой современную реализацию классической игры «Морской бой», написанную на чистом JavaScript (Vanilla JS) без использования сторонних тяжелых фреймворков. Игра полностью адаптирована под сенсорные экраны смартфонов и ПК, имеет гибкую систему расстановки кораблей и полноценного AI-соперника.

---

## ✨ Реализованный функционал

### 🎮 Игровые режимы:
* **Игра против ИИ (Бот):** Искусственный интеллект с несколькими уровнями сложности и алгоритмом автоматического поиска и добивания подбитых палуб.
* **Режим на двоих (Pass & Play):** Игра с другом на одном устройстве с промежуточным экраном передачи хода, скрывающим флот противника.

### 🛠 Механики и интерфейс:
* **Удобная расстановка:** Визуальная подсветка зоны размещения корабля (зеленая/красная тень) с точным позиционированием.
* **Поворот кораблей:** Возможность поворота кораблей по кнопке на экране (для мобильных устройств) или по клавише `R` / `К` на клавиатуре.
* **Умный алгоритм ИИ:** Защита от зависаний и исключение выстрелов в заблокированные зоны («ореол» вокруг затонувших кораблей).
* **Синтез звука (Web Audio API):** Динамическая генерация звуков выстрелов, промахов, попаданий и победы без загрузки сторонних mp3-файлов.
* **Боевой журнал (Combat Log):** Текстовая трансляция всех событий боя в реальном времени.
* **Адаптивный UI:** Верстка под все типы экранов с использованием Tailwind CSS.

---

## 🛠 Использованные технологии

* **HTML5** — семантическая структура и сетка игровых полей (CSS Grid $10 \times 10$).
* **Tailwind CSS** — стилизация, адаптивные сетки, шрифты и тёмная неоновая тема.
* **JavaScript (ES6+)** — клиентская логика, обработка событий touch/click, Web Audio API, алгоритмы ИИ.
* **Netlify** — хостинг и непрерывное развертывание (Continuous Deployment).
* **Git / GitHub** — система контроля версий.

## 🤖 Использование AI-инструментов (AI Assistance)

В процессе разработки приложения активно применялся ИИ-ассистент (**Gemini / ChatGPT**) для решения следующих задач:
1. **Проектирование логики:** Генерация архитектуры состояния игры (`state management`) и структуры игровых фаз.
2. **Отладка и рефакторинг (Bug Fixing):**
   * Расчет правильной математической формулы позиционирования тени предпросмотра кораблей в CSS Grid.
   * Устранение состояния зацикливания («Deadlock») в очереди атак ИИ при взаимодействии с автоматически помечаемыми клетками ореола.
   * Настройка корректной передачи очереди хода при промахах.
3. **Адаптация под мобильные устройства:** Оптимизация интерфейса управления и проектирование сенсорных элементов (кнопки поворота) для браузеров на смартфонах.
